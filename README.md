# LicitaDoc — Gestão de Licitações e Conformidade Documental 

**Curso:** Engenharia de Software — Instituto Infnet  
**Disciplina:** Projeto de Bloco: Engenharia de Produto de Software e Inovação   
**Aluna:** Felícia Kethellyn Vieira De Souza  

## Sobre o Projeto
Sistema voltado para Micro e Pequenas Empresas (MPEs) que atuam em compras públicas, centralizando o controle de Atas de Registro de Preços assinadas, abatimento automático de pedidos (empenhos) e monitoramento preventivo de certidões negativas e documentos de habilitação.
